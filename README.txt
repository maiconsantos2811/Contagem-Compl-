CONTAGEM DE CHOPE — PROJETO ANDROID

Este pacote contém o projeto Android baseado na versão atual da aplicação.

IMPORTANTE:
- Ele é um projeto para gerar o APK, não um APK já compilado.
- Para gerar o APK é necessário um ambiente Android/Node com Capacitor.
- A forma mais simples é abrir o projeto no Android Studio depois de instalar as dependências do Capacitor.

Passos principais:
1. Instale Node.js e Android Studio.
2. Abra esta pasta no terminal.
3. Execute: npm install
4. Execute: npx cap add android
5. Execute: npx cap sync android
6. Execute: npx cap open android
7. No Android Studio, gere o APK em Build > Build APK(s).

O conteúdo da aplicação está em www/index.html.
